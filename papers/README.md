## 收录方式

- 保留明确的论文版本与正式来源，避免不同版本混放
- 可再分发的原文和图片同时记录许可、出处及 SHA-256 校验值
- 再分发许可尚不明确的资料仅保留官方链接
- 本目录用于公开文献资料归档
