# codex_files

公开学术资料存储库。仅收录已确认允许再分发的论文文件、配图及其来源信息。

## 收录规则

- 每个文件保留原作者、论文标题、官方来源、明确版本、许可证据及 SHA-256 校验值
- 论文可公开阅读不等于允许重新分发；许可不明确时仅保存官方链接
- 论文中的第三方图片可能有独立权利说明，单独核查
- 裁剪、格式转换或重绘必须注明，不冒充未经修改的原图
- 不上传私人笔记、未公开研究想法、研究方向评估、账号信息、凭据或私有项目备份
- 第三方文件的权利归原权利人，本仓库不对其统一重新授权

## 目录约定

- papers/：允许再分发的论文原文，按论文和版本组织
- figures/：允许再分发的论文配图
- sources/：对应的公开来源、许可和文件校验记录

文件会在逐项核验后分批加入。
