# codex_files

公开学术资料存储库，仅收录已确认允许再分发的论文原文、配图及来源信息。

## 资料导航

- [VARSR · ICML 2025 正式版](papers/varsr/icml-2025/)：论文、Figure 2、署名许可与文件校验记录

## 目录约定

统一按 papers/<论文标识>/<明确版本>/ 归档，不把论文和图片堆在根目录。

每个版本目录包含：
- paper.pdf：未修改的论文原件
- figure-02.png 等：按原图号命名的图片；图较多时使用 figures/ 子目录
- ATTRIBUTION.md：作者署名、引用、许可和修改说明
- sources.json：官方来源、版本、文件路径、字节数及 SHA-256

同一论文的预印本修订版与正式出版版分目录保存。公开分类仅使用论文公开信息，不反映私人研究规划。

## 收录规则

- 论文可公开阅读不等于允许再分发；许可不明确时只记录官方链接
- 第三方图片的独立权利说明需单独核查
- 裁剪、格式转换或重绘必须注明，不冒充未经修改的原图
- 不上传私人笔记、未公开研究想法、研究方向评估、账号信息、凭据或私有项目备份
- 第三方文件的权利归原权利人，本仓库不对其统一重新授权
- 文件在逐项核验后分批加入；远端校验通过后才清理临时传输副本
